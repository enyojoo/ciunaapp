Rules

Use
  • Order is fixed: en, ru, fr, es, zh, pt. The default language is marked and required.
  • Each tab carries a status dot plus a word in the tooltip; the missing banner names the field.
  • Show the default-language text as a hint under other languages for reference.
  • Fallback is the default language, and the banner says so.
Don't
  • Don't block saving because an optional language is empty.
  • Don't auto-translate silently; machine translation needs a visible badge and an edit.
  • Don't show flags for languages.
