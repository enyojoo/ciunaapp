# StatusBadge

## Purpose
One word status in one colour pair.

## Anatomy
Dot or icon + word.

## States
Tones: success, warning, destructive, neutral. Map by status word, never by caller colour.

## Rules
Word list is in README principles. Never orange. Never colour alone.

## Upgrade
Replaces the ad-hoc status colours in web and mobile `status-chip`.
