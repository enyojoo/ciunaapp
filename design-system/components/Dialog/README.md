# Dialog

## Purpose
Confirm dialog with a direct question and reason field, plain information dialog, and the bottom-sheet version on a phone

## Anatomy

## Rules
Use tokens from `tokens.json` through `bundle.css`; no hardcoded colours or sizes. Targets are at least 44px. Never convey meaning by colour alone.
