Rules

Use
  • State the size and ratio next to the control. Show a preview as soon as the file is picked.
  • Reorder by handle on desktop; "Move earlier / later" in the menu on phones for keyboard and touch parity.
  • Empty slots stay visible so the limit is clear.
Don't
  • Don't stretch a photo to fit; crop with a preview.
  • Don't bury remove: one tap with an undo toast, no confirm dialog.
  • Don't allow upload without alt text on product photos where the form asks for it.
