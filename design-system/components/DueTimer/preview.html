Default 28px in cards and rows; 36px in the order detail header. It refreshes every 30 seconds, so it never shows seconds.

Use

  • Show it only while the order is New, Accepted or Preparing.
  • Say how long, in the seller's language.
  • Pair every colour with the words Due or Overdue.

Don't

  • Don't use orange or red for a running timer.
  • Don't show a live seconds countdown.
  • Don't hide an overdue timer after a while.
