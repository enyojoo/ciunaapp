Rules

  • Sentence case everywhere. Caps only for the eyebrow style.
  • Minimum 13px for text that matters, 11px only for eyebrows and tab labels. Works at 200% text size.
  • Body copy uses ink or muted. Orange text uses primary-text.
  • Names, addresses and listing titles accept any script and wrap or truncate with an ellipsis, never overflow.
  • Native screens use the system font; web uses Geist. Do not mix on one screen.
