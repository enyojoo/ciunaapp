Rules

Use
  • Primary fill for work in progress; success only when finished, destructive only on failure.
  • Always pair the bar with a text value (percent, step, or amount).
  • role="progressbar" with aria-valuenow; indeterminate omits the value.
Don't
  • Don't animate a fake progress; use indeterminate when unknown.
  • Don't use a bar for status: use a badge.
  • Don't make it thicker than 12px.
