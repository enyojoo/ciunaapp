Principles

Neutrals carry the surface. Orange signals intent: the one thing to do. Three oranges exist because white text, orange text and a logo have different contrast needs. Every pairing below is checked against WCAG AA by npm run design:check. Hex values are shown for reference; code always uses the token.

Brand and primary

Which orange?

USE FOR CONTROLS

primary

Fill behind a white label: buttons, active tabs, selected chips, count bubbles, focus rings. Hover goes deeper to primary-hover.
