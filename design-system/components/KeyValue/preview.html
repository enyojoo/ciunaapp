Rules

Use
  • Use a real <dl>. Label is muted, value is ink.
  • Total row is bold with a hairline above; the label states what it is: "Total paid", "Paid out to ••4821".
  • Dates with the time zone: "Sep 24, 2026 • 2:14 PM MSK".
Don't
  • Don't put a table in a card where a definition list will do.
  • Don't centre values or mix alignments in one list.
  • Don't name payment providers on customer or seller receipts.
