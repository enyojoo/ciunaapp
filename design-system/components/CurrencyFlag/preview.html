Rules

  • A currency is named by flag and code together: RUB, USD. The flag never stands alone; it is aria-hidden when the code is beside it.
  • Pickers show flag, code, full name and symbol. Search matches code, name and country.
  • Selected row: primary-tint, primary-text name, check. Unselected rows show an empty radio.
  • Suggested first (the user's wallet currency and recent), then the rest alphabetically by code.
  • EUR uses the circle of 12 stars, not a country. USD uses the US flag.
  • Flags are decorative identifiers, not political statements: use currency and country consistently and never crop or recolour them.
  • Rows are 56px tall, whole row is the tap target.
