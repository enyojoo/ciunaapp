What is shared and what is not

Shared

  • Tokens. tokens.json generates web, Seller and Office CSS, the Expo theme and Tailwind config. npm run design:sync keeps them in step; design:check fails on drift and on text pairs under AA.
  • Rules in packages/shared. Money formatting, status vocabulary, locales (six languages), hub service lines.
  • packages/ui-web. Button, Input, Select, Field, Switch, StatusBadge, Card, PageHeader, Banner, EmptyState, Skeleton, Amount, Sheet, ConfirmDialog, Toast, Tabs, LanguageTabs. Seller uses it today; web and Office still use their own copies.
  • Vocabulary. Button labels, status words, errors, the 48px tap target and the light-only rule.

Not shared

  • The shell. Each app owns its layout, nav list and breakpoints (seller/components/shell, office/components/layout, web/components/layout, mobile/app/(app)/_layout.tsx). Nothing generic renders "an app shell".
  • Native components. The Expo app builds its own React Native components; ui-web is web only.
  • Type. Geist on web, the system font on native, by design.
  • Density. No dense Office tables on customer screens; no big tiles in Office.
  • Providers. Only Office names payment providers.
