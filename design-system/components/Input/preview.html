Rules

Use
  • A visible label above every field. Placeholder shows an example, never the label.
  • Input edge input-edge (3:1), height 44 desktop, 48 on phones.
  • Error text says what to fix, with an icon, under the field.
  • inputMode for numbers and phones so the right keyboard opens.
Don't
  • Don't turn the border red alone: pair it with the error text.
  • Don't validate while the user is still typing; validate on blur or submit.
  • Don't use disabled to hide why something is locked: say why in the hint.
  • Don't put a unit in the label if a suffix can carry it.
