## Cross-cutting notes
- Time zone naming: none of formatDateTimeLine (`lib/transactions.ts:96`), transfer timeline, receipts, expert slots show the zone consistently as the cards require. One shared helper `formatDateTimeZone(iso, locale, timeZone?)` with `timeZoneName: "short"` would fix transfer detail, receipts, booking summary and expert next-available in one place.
- `refunded` is a real transfer status on the server (receipts) but unknown to the client (`statusTone`), affecting list, detail and receipt entry. Highest-value single fix.
- Hard-coded English in `MobileBitbankerPayCard` ("Pay with SBP", "Open payment link", "Payment", "SBP") breaks the six-language rule.
- Offline: no screen in this set shows the card's quiet per-screen offline line; only the global pill. Where cached data exists but the revalidate errored, add the one-line message (directory, profile, transactions already partial).
