# Audit D: Send, SendWeb, SendAmountField, Recipients, Kyc, Limits

Method: read READMEs and preview text, then mobile code (send.tsx, components/send/*, recipients/*, verification/*, limits.tsx, orders/[id].tsx). Only shot available is limits.png (it matches the card closely). Nothing was run; states below are from code.

Deliberate deviations (not gaps): Customer web is Expo web, `web/` not ported (decisions 2026-10-18). Customer app matches design system (2026-10-16) but checkout/payment contracts frozen. Send limits: Office sets amounts, nothing seeded, no limit means no cap (2026-10-18). Placeholder numbers are examples. Provider-name rule applies to customer copy. Limits README "Upgrade" already records limits.tsx as built; Office limits editor is out of scope here.
